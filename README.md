# Vector Database Comparison: Qdrant vs Amazon S3 Vectors

##  Project Overview

This project compares **Qdrant** and **Amazon S3 Vectors** to understand:

- How they store vector embeddings
- How search works in each system
- Performance and architectural differences
- When to use which system
- Trade-offs (cost, scalability, flexibility, vendor lock-in)

The goal is to provide a hands-on technical comparison using real code examples.

---

##  Technologies Used

- Python 3.11+
- Docker
- Qdrant (Self-hosted)
- Amazon S3 Vectors (AWS Managed Service)
